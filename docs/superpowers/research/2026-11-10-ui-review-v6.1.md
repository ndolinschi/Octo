## 2. Findings

### P1
1. **Breadcrumb row collides and collapses at the default split** — `components/files/FileView.tsx` (`Crumbs`, the `h-bar` row). a3.js on `docs-site/src/content/docs/getting-started.md`, 1440 window, 576px group: folder crumbs are 16px each (one letter), and after an edit "Unsaved" (x 1204–1253) overlaps "Preview" (1240–1301) by 13px (`a3-crumb-dirty.png`, `n1-md-preview-edited.png`). The "content" crumb's tooltip says "Reveal docs-site/src/content/docs" (wrong path). Fix: collapse to "… › parent › file" whenever the crumbs do not fit (measure, not "> 3 folders"); give the status slot `shrink-0` and let crumbs take what is left; shorten the file name once; fix the tooltip index.
2. **Streak is cut by a hard edge on the empty project** — `primitives/StreakLayer.tsx` as mounted by the empty conversation (`components/chat/ConversationView.tsx`). `X-emptyproj-dark-crop.png`: the band starts at a straight horizontal line under the opaque chat header (y≈85) and reads as a cropped image; the scrim leaves a visible darker rectangle around the centred block. Home and the hero are fine (band runs to the panel edge). Fix: mount the layer on the panel (behind strip and header, header transparent in the empty state) or mask the top 80px to 0; widen the scrim feather.
3. **Tree hierarchy is ambiguous without folder glyphs** — `components/files/FileTree.tsx` row anatomy. A file's glyph sits where a sibling folder's label starts, so its label is 24px right of sibling folder labels: `tools ›` followed by `.env.example`, `http ›` followed by `index.ts` read as children of the collapsed folder (`e3-files.png`, `S-file-1100-960.png`). Fix: put the file glyph in the chevron column (same x as the chevron), so sibling labels share one left edge.
4. **Details has no measure** — `components/details/DetailsPanel.tsx`. Alone in a wide group (960 window: 944px) labels sit at x=25 and values at x=935 (`n1-details-960.png`); token bars stretch to 470px. Fix: `max-w-[480px]` (or `measure`) on the section column.
5. **Narrow groups hide tabs** — `components/dock/TabStrip.tsx` + `WorkspaceActions.tsx`. After a drag split a group is 288px; the five header tools leave 91px for tabs (min tab 96), so a second tab scrolls out with only a fade as cue (D3.js: tab at x=1029 outside a group starting at 1142; `D3-narrow-group.png`). Fix: collapse the tools into the `…` menu under ~420px.
6. **Home cards stretch into dead space and the block jumps** — `components/home/Home.tsx`. "191 more" grows Recent requests to 514px; This month stretches to match with ~120px gaps between its three rows; the centred block moves up 42px under the pointer (h3.js: h1 y 91→49; `h1-more.png`). Fix: `items-start` on the grid row (or cap the list at 5 + link), top-anchor the block once it exceeds the viewport.
7. **Tokens card's day row carries no information** — `Home.tsx` (`role="img"` "Tokens per day"). h2.js: 29 bars are 2px or the 8% floor, one bar is full height (`e1-home.png`). It reads as a rendering fault. Fix: hide the row when max/median > ~20, or use a sqrt/log scale; do not ship the linear version.

- Comment lane: "+" 856–874, numbers 875–898, first glyph ≥ 924 on column-1, space- and tab-indented lines; no gutter shift on hover; add / edit / remove / Ctrl+Alt+C / Esc.
- Home numbers: heat-cell titles sum to 165 = caption; 5 + 191 = 196 requests; Details token rows sum to the total; Integrations 7+3+3 = 13, chips `aria-pressed`, counts follow the search, 2 columns → 1 at 390, `?plugins=none` "No plugins loaded."
- Streak contrast, worst pixel behind every text run (text hidden, DPR 1, static): Home ≥ 6.5 dark / 5.0 light, empty project 5.8 / 5.5, hero 9.2 / 9.4, at all five widths. No banding (ordered dither visible, fine). Reduced motion: no drift animation. `aria-hidden`, pointer-events none.
- File link `path:12-20` selects lines 12–20; numeric table columns right-aligned with tabular numerals; time separators 12px.
- 200% zoom: no horizontal scroll, dialogs fit and scroll. No horizontal page scroll at any width.
- Console: 0 errors, 0 warnings in every run (all widths/themes, `?lsp=fail-once|slow|exit`, `?plugins=none`, `?demo=…`, LIVE).

## 5. Verdict
Close, not yet "premium". v6's broken entry points are gone, the LIVE path works end to end, drag and drop is solid, code highlighting and the comment lane are exact. What still reads as unfinished is edge geometry on the new work: the breadcrumb row at the default split, the streak's hard cut, the tree without a stable label edge, and unbounded/stretching panels (Details, Home cards, the token bar row).
Three changes that move it most: (1) breadcrumb row that measures and never overlaps; (2) file glyph in the chevron column so the tree has one label edge per level; (3) bound and settle the new surfaces — Details max width, Home cards top-aligned, drop or rescale the token day row, streak mounted behind the header.
